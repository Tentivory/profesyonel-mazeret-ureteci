# 🏛️ PROFESYONEL MAZERET ÜRETECİ

### Dünyanın En Gelişmiş, En Bilimsel ve En Ciddi Tembellik Destek Sistemi

---

## 📜 Proje Hakkında

Bu repository, insanlık tarihinin en büyük problemlerinden birini çözmek amacıyla kurulmuştur:  
**"İnsanlar neden işe, okula veya toplantılara gitmek istemez?"**

Yıllarca süren araştırmalar, 47 peer-reviewed makale ve 3 adet hayali Nobel Ödülü adaylığının ardından,  
**Profesyonel Mazeret Üreteci** doğmuştur.

Bu yazılım, klasik "hastayım" veya "trafik vardı" gibi amatör mazeretleri geride bırakır.  
Bunun yerine **kuantum fiziği, astroloji, kedi diplomasi ve rüya hukuku** gibi  
yüksek seviye bilimsel disiplinlerden beslenerek mazeret üretir.

---

## 🚀 Özellikler

- ✅ %99.9 inandırıcılık oranı (laboratuvar ortamında test edilmiştir)
- ✅ 15+ bilimsel temelli mazeret şablonu
- ✅ Otomatik detay ve sonuç cümlesi ekleme
- ✅ Terminal animasyonu ile profesyonel his
- ✅ Yasal sorumluluk reddi dahil
- ✅ Tamamen Türkçe arayüz (millî teknoloji hamlesi)

---

## 📦 Kurulum

```bash
git clone https://github.com/Tentivory/profesyonel-mazeret-ureteci.git
cd profesyonel-mazeret-ureteci
python3 mazeret_ureteci.py
```

Başka bir şey kurmanıza gerek yok. Python 3 yeterlidir.  
(Eğer Python yoksa, bu da ayrı bir mazeret konusu olabilir.)
